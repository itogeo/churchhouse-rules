1. The gist
One letter, twelve categories, a timer: score only for answers nobody else thought of.

2. Players and time


3. Materials and links
Scattergories set (letter die, category cards, timer) or paper and a list of categories

4. Setup
Everyone gets the same list of 12 categories. Roll the letter die.

5. How to play
Start the timer. Write one answer per category, each starting with the rolled letter. When time's up, read answers aloud. You score a point for each valid answer no one else wrote. Alliteration (e.g. "Big Bird" for B) earns a point per matching word. Play three rounds.
