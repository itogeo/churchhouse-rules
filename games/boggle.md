1. The gist
Speed word-find in a shaken grid of letter cubes.

2. Players and time
2+

3. Materials and links
Boggle set (16 or 25 letter cubes, tray, 3-minute timer), paper and pens

4. Setup
Shake the tray so every cube lands in a slot, then start the timer.

5. How to play
Everyone writes down words made from adjacent letters (including diagonals), each cube used once per word, 3+ letters. When time's up, read lists aloud and cross out any word someone else also found. Score the rest: 3-4 letters = 1, 5 = 2, 6 = 3, 7 = 5, 8+ = 11.

6. Variations
Big Boggle: 5x5 grid, 4-letter minimum.

7. Rulemaster
Allan Turoff (Parker Brothers, 1972)
